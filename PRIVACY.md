# Política de privacidade — Artemis

Última atualização: 17 de novembro de 2026.

A Artemis não coleta, transmite, vende ou compartilha dados pessoais.

As paletas, preferências e os atalhos personalizados são armazenados localmente no navegador por meio de `localStorage`.

A permissão `topSites` é usada somente para exibir, na própria página de nova aba, uma lista dos sites mais visitados fornecida pelo navegador. Essa lista não é enviada para servidores externos nem armazenada pela Artemis.

As pesquisas são abertas diretamente no mecanismo escolhido pelo usuário. A partir desse momento, aplicam-se os termos e políticas do respectivo serviço.
